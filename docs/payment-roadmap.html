/ Phase 01

办理个体工商户营业执照 全程线上

所有支付渠道的准入前提。北京支持非京籍办理，难点只在注册地址。

  1. 解决注册地址（二选一）
    北京要求经营场所为非住宅规划用途的固定场所，住宅不能注册。纯线上业务走：
    • 网店地址方案（推荐）：在北京市公示的九个电商平台（淘宝 / 拼多多等）开设网店， 下载「网络经营场所使用证明」，用它作为经营场所登记，无需实体店面； 外地来京人员需持北京居住证（卡）
    • 园区 / 集中办公区地址：部分园区提供收费注册地址（公司用得多，个体户也可咨询）
  2. 北京市企业服务 e 窗通提交设立登记
    搜索「个体工商户开办」一件事；准备：身份证、经营场所证明、经营范围 （建议含 软件开发；数字文化创意内容应用服务；互联网销售 等）
  3. 领照 + 收款卡
    执照 1–3 个工作日下发。个体户可用经营者本人银行卡收款 （微信支付明确支持法人对私账户，不强制开对公户）
经营范围别写窄。后续支付宝签约要看网站经营内容与执照一致性， 覆盖「软件开发 / 信息服务 / 互联网销售」能避免二次变更。

/ Phase 02

ICP 备案：主体变更到个体户 整条链路的等待大头

支付宝与微信均要求：网站可正常访问、经营内容完整、备案主体与支付签约主体一致。

  1. 确认现状
    若域名当前为个人备案 → 办理「主体变更 / 注销重备」到个体户名下（在服务器所在云的备案系统操作： 阿里云 beian.aliyun.com / 腾讯云 console.cloud.tencent.com/beijing）
  2. 提交材料
    个体户营业执照、经营者身份证、核验（人脸 / 幕布，按管局要求）、网站信息 （名称、服务内容 — 选「其他信息服务 / 信息技术」类）
  3. 等待管局审核
    云初审 1–2 天 + 管局审核最长 20 个工作日（北京通常 1–2 周出结果）。 期间保持备案负责人电话畅通，驳回常见原因：网站名称含商用词、内容与主体不符
备案期间网站可正常访问（主体变更情形），但支付签约必须等备案通过—— 所以这一步越早启动越好，Phase 3 / 4 的材料可以并行准备。

/ Phase 03

支付宝开放平台：电脑网站支付 支持个体户

CNY 区的默认支付方式（跳转支付宝收银台，人民币直结到你的账户）。

  1. 注册开放平台账号并完成企业认证
    open.alipay.com → 入驻 → 主体选个体工商户，用营业执照 + 经营者支付宝账号实名
  2. 创建自研应用，签约「电脑网站支付」
    填写应用名称 / 图标 / 网址（你的备案域名）；签约时网站需展示完整经营内容与商品信息 （定价页已有：credits 档位 + HDA license）
  3. 配置接口加签（RSA2）
    用支付宝密钥工具生成应用密钥对 → 上传应用公钥 → 平台生成支付宝公钥。 保存：应用私钥（填 ALIPAY_PRIVATE_KEY）与支付宝公钥（填 ALIPAY_PUBLIC_KEY， 注意不是你的应用公钥）
  4. 回填 api/.env
    回调地址无需在平台配置，下单时已携带：https://你的域名/api/webhooks/alipay

/ Phase 04

微信支付商户号：Native 扫码 支持个体户

PC 网站扫码支付，前端自动弹二维码并轮询支付结果。

  1. 申请商户号（个体户通道）
    pay.weixin.qq.com → 接入微信支付；材料：营业执照彩色扫描、经营者身份证、 银行账户（对公或经营者对私均可）
  2. 开通 Native 支付产品
    商户平台 → 产品中心 → Native 支付 → 开通（≤7 个工作日）； 需要一个已备案的自有网站（Phase 02 的成果）
  3. API 安全三件套
    申请 API 证书 → 记录证书序列号（WXPAY_SERIAL_NO）、 下载 apiclient_key.pem（WXPAY_PRIVATE_KEY）、设置 APIv3 密钥（WXPAY_APIV3_KEY，32 位）； 平台证书代码会自动拉取缓存，无需手动配置
  4. 绑定 APPID 并回填 env
    绑定一个公众号 / 开放平台应用 APPID（WXPAY_APPID）； 回调地址固定为 https://你的域名/api/webhooks/wechat

/ Phase 05

配置上线与验收 半天搞定

三家渠道共用同一套订单 / 发货体系，填好密钥重启即从 mock 切换到真实网关。

# api/.env — 生产
PUBLIC_ORIGIN=https://你的域名        # 回调与跳转的根（必填）
#FRONTEND_ORIGIN=…                   # 仅前后端分离部署时需要

ALIPAY_APP_ID=2021…
ALIPAY_PRIVATE_KEY=MIIEvQ…            # 应用私钥（PKCS8）
ALIPAY_PUBLIC_KEY=MIIBIjANBg…        # 支付宝公钥

WXPAY_MCHID=19000…
WXPAY_APPID=wx…
WXPAY_SERIAL_NO=5157F0…
WXPAY_PRIVATE_KEY=/srv/secrets/apiclient_key.pem
WXPAY_APIV3_KEY=32位字符串…

#PAYMENT_MOCK=1                      # ⚠️ 生产绝不开启（且 prod 自动拒绝）
  • 重启 API 后，CNY 定价页出现「支付宝 / 微信支付」两个入口（mock 入口消失）
  • 真实支付最小档验证：¥35 Starter 走一遍支付宝、一遍微信扫码
  • 确认：用户积分到账、payments 表该行 status=completed、 商户后台能看到交易并可对账
  • 故意断网 / 等待 5 分钟后再支付，确认回调幂等（积分不会重复增加）
  • 订单流程试一笔 HDA license（¥169 个人版），确认签名下载链接可用

/ Appendix A

税费优惠与补贴速查（北京 · 2026）

最值钱的是国家层面的税费减免（个体户直接享受），市级补贴以贴息贷款和小额一次性补贴为主。

项目内容条件 / 截止
增值税免征 小规模纳税人月销售额 ≤10 万免征；超过部分 3% 减按 1% 政策延续至 2027-12-31
经营所得个税减半 年应纳税所得额 ≤200 万的部分减半征收，可叠加其他优惠 政策延续至 2027-12-31
「六税两费」减半 资源税、城建税、房产税、城镇土地使用税、印花税、耕地占用税 + 教育费附加、地方教育附加 至 2027-12-31
创业担保贷款（北京） 个人最高 50 万、最长 3 年，财政贴息（自付 LPR−150BP 以下部分） 在本市注册经营、资信良好；是贴息贷款不是补贴
一次性创业补贴（北京） 8000 元，招用本市户籍劳动力可加，封顶 1 万 首次创办 + 本人以该组织名义缴社保满 6 个月 + 纳税满 1 年； 非京籍灵活就业参保受限，较难满足
高新认定 / 专精特新奖励 部分区一次性 10–30 万 + 企业所得税 15% 需公司主体 + 知识产权 + 研发费用归集 — 未来升级公司后再够

/ Appendix B

个体户 vs 一人有限公司：怎么选

维度个体工商户一人有限公司
所得税 经营所得 5%–35% 累进 + 200 万内减半；无分红税 企业所得税（小微利实际 ≈5%）+ 分红 20% 个税
出资 无实缴要求 注册资本 5 年内实缴（新《公司法》2024.7.1）
责任 无限责任 有限责任，但不能证明财产独立时承担连带责任（举证责任在股东）
维护成本 极低，记账简单 代理记账约 200–400 元/月，注销复杂
升级空间 雇人、高新认定、融资、部分平台入驻受限 全部可用
结论：年利润几十万以内 → 个体户到手更多、省心； 利润稳定超过约 70 万、要雇人 / 申请高新 / 对外融资 → 再设公司。 若担心一人公司限制，可注册普通有限公司（家人挂 1% 股权）绕开特别规定； 注册资本别认缴虚高，5 年内要真金白银实缴。
